# TratoBot - Бот для учёта финансов

Телеграм-бот для учёта личных финансов "Завтра на диете".

## Возможности

- Настройка бюджета (доход, обязательные платежи, "Чёрный день", "Хотелка")
- Отслеживание трат
- Дневной лимит
- Категоризация расходов

## Команды

- `/start` — начать работу
- `/budget` — настроить бюджет
- `/add` — добавить трату
- `/status` — показать статус

## Запуск локально

```bash
pip install -r requirements.txt
python -m src.bot.main
```

## Деплой на Railway

1. Создай проект на railway.app
2. Подключи GitHub репозиторий
3. Добавь переменную BOT_TOKEN в.env
4. Задеплой
